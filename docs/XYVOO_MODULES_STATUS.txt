================================================================================
XYVOO — MODULE STATUS GUIDE
What is built vs what is not (as of June 2026)
================================================================================

This document lists every major module for both XYVOO products and states
clearly what works today, what is partly done, and what is still only planned
or marketing copy.

Repositories:
  xyvoo-next  = Hotel HMS app (most hotel code lives here)
  xyvoo       = Online Store app (ecommerce code lives here)

Status labels used in this file:
  [BUILT]     Real UI + database/API; usable in production-style flows
  [PARTIAL]   Meaningful work shipped, but major gaps remain
  [SCAFFOLD]  Page exists with checklist/placeholder; little or no backend
  [PLANNED]   Described in PRD/FAQs/marketing; no real module yet
  [MARKETING] Claimed on website/FAQs; not implemented in code

================================================================================
HOW TO READ THIS FILE
================================================================================

"BUILT" does not always mean "feature complete for every PRD card."
Front Desk, for example, has many working flows but 39 PRD capability cards
still say "Coming soon."

When in doubt, trust this file over marketing FAQs for what actually runs.
