PART 0 — PLATFORM OVERVIEW
================================================================================

0.1 WHAT IS XYVOO?
------------------
XYVOO is a multi-product business platform built for African businesses. It
offers two separate products on shared infrastructure:

  1. XYVOO HMS  — Hotel / hospitality management (PMS + operations)
  2. XYVOO Store — Multi-tenant e-commerce for online merchants

Both products are white-label: tenants run under their own brand (name, logo,
colours). XYVOO is invisible to staff, guests, and shoppers.

0.2 PRODUCT PROMISE (PLATFORM)
------------------------------
  - Single full-featured plan per product (no per-module tier locks on HMS)
  - African-market first: Naira pricing, Paystack, local operations reality
  - Web-first + PWA (install to home screen, no app store required)
  - Department-scoped staff access (HMS) / role-based dashboard (Store)
  - Multi-tenant isolation: each business gets slug/subdomain + tenant_id

0.3 TARGET CUSTOMERS
--------------------
Hospitality:
  - Independent hotels, boutique hotels, resorts, serviced apartments
  - Hotel chains and multi-property groups (roadmap: group roll-up)

Retail / e-commerce:
  - Retailers, product businesses, SMBs selling online
  - Hotels with gift shops / resort boutiques (can use both products)

0.4 PERSONAS (CROSS-PRODUCT)
------------------------------
  - Prospect          → marketing site, pricing, contact, register
  - Business owner    → full setup, billing, staff, branding
  - Department staff  → scoped operational UI (HMS stations / Store roles)
  - Platform operator → @xyvoo.com internal admin, tenant directory
  - Guest / shopper   → hotel guest flows, store storefront (no XYVOO branding)

0.5 NON-GOALS (CURRENT PHASE)
-----------------------------
  - Native iOS/Android app store apps (PWA is in scope)
  - Full OTA/channel-manager parity on day one (marketing claims roadmap)
  - Single login across unrelated hotel + store tenants (unless same org)

PART 1 — XYVOO HMS (HOTEL MANAGEMENT SYSTEM)
================================================================================

1.1 VISION & PROBLEM STATEMENT
------------------------------
Vision:
  Give independent hotels chain-grade PMS and operations software without
  enterprise cost or complexity — tuned for African markets.

Problems solved:
  - Fragmented tools (spreadsheets, WhatsApp, paper) for reservations and ops
  - Weak staff access control (shared logins, everyone sees everything)
  - Slow check-in, poor room/housekeeping visibility
  - Unaffordable or ill-fitting international HMS for smaller properties

1.2 GOALS
---------
  G1  Authenticated users onboard or join a hotel tenant; land in correct UX
  G2  Each hotel isolated by tenant (slug + hotel schema + RLS)
  G3  Operators configure branding, staff, modules from consistent HMS shell
  G4  Marketing drives conversion to registration
  G5  Security: protected routes; Supabase session; server-only secrets

1.3 PRICING & BILLING (HMS)
---------------------------
Model: Single plan, all features included. Billing cycle choice only.

  Monthly:    ₦200,000 / month
  Quarterly:  ₦550,000 / quarter (save 8%)
  Yearly:     ₦2,000,000 / year (save 17%)

  - 14-day free trial, full access, no credit card to start
  - Unlimited rooms (no per-room pricing)
  - Payment via Paystack (cards, bank transfer, Visa/Mastercard/Verve)
  - End of trial without payment → read-only mode (data retained)

PART 2 — XYVOO STORE (E-COMMERCE PLATFORM)
================================================================================

2.1 VISION & PROBLEM STATEMENT
------------------------------
Vision:
  Let merchants launch a branded online store in minutes — catalog, checkout,
  orders, and marketing — without building a custom site or juggling bolt-ons.

Problems solved:
  - High cost/time to build and host ecommerce
  - Fragmented tools for products, orders, payments, shipping
  - Platform fees and feature gates on competitor tiers
  - Lack of Africa-ready payment rails (Paystack first)

Implementation note:
  Store application code lives primarily in the **xyvoo** repository.
  **xyvoo-next** hosts marketing, pricing, FAQs, and placeholder register/login
  routes (/register/store, /auth/login/store) until unified or linked.

2.2 GOALS
---------
  G1  Merchant self-serve signup → live storefront on subdomain
  G2  Multi-tenant isolation (store schema + tenant_id + RLS, product=store)
  G3  Merchant dashboard for full commerce operations
  G4  Shopper-facing PWA storefront (catalog, cart, checkout)
  G5  Clear fee model: Free (4% per order) vs Standard (₦10k/mo, 0% fee)

2.3 PRICING & PLANS (STORE)
---------------------------
  Free:
    ₦0/month, 4% platform fee per order
    Unlimited products, website + PWA, Paystack, invoices/receipts/discounts,
    analytics dashboard

  Standard:
    ₦10,000/month, 0% platform fee
    Everything in Free + enhanced analytics, marketing tools, export reports,
    priority support, custom domain (per comparison matrix)

  Enterprise:
    Custom pricing, custom transaction fees
    Dedicated support, custom automations, enterprise integrations, SLA,
    API access, additional payment gateways

Feature comparison matrix: 50+ rows across core platform, analytics, PWA,
custom domain, SEO/marketing, notifications, discounts, shipping/tax,
team/RBAC, integrations/API, payments/checkout, support
(see src/constants/pricing.ts STORE_FEATURE_COMPARISON_ROWS)
