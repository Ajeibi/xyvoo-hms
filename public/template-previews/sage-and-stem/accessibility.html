Our aim

We want everyone to be able to browse and buy from us, whatever device or assistive technology they use. We design and test this website against the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA.

Using this website

You should be able to:

  • zoom in up to 400% without text spilling off the screen
  • navigate the whole site using just a keyboard
  • use the site with a screen reader, such as NVDA, JAWS or VoiceOver
  • turn off animations using your device's reduced motion setting
  • use Windows high contrast mode
